# legs

<!-- badges: start -->
<!-- badges: end -->

A TUI interface for viewing R data

## Installation

You can install the development version of legs from [GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("ryanzomorrodi/legs")
```
